# Supabase Learning Hub

Welcome to the Supabase Learning Hub! This is a dedicated space for learning and experimenting with Supabase features and capabilities.

## What is Supabase?

Supabase is an open-source Firebase alternative that provides:
- **Database**: PostgreSQL with real-time subscriptions
- **Authentication**: User management with various providers
- **Storage**: File and media storage
- **Edge Functions**: Server-side functions
- **Realtime**: Listen to database changes in real-time

## Learning Objectives

This hub will help you learn:
- [ ] Setting up a Supabase project
- [ ] Database design and management
- [ ] Authentication flows

- [ ] File storage and management

- [ ] Integration with React applications

## Getting Started

1. **Prerequisites**
   - Node.js (v16 or later)
   - npm or yarn
   - A Supabase account (free at https://supabase.com)

2. **Setup**
   ```bash
   cd supabase-learning-hub
   npm install
   ```

3. **Create your first Supabase project**
   - Go to https://supabase.com/dashboard
   - Create a new project
   - Copy your project URL and anon key

4. **Start learning!**
   - Check out the `docs/` folder for guides
   - Try the examples in `examples/`
   - Build your own projects in `projects/`
